> LazyLoop hires an even lazier AI agent to do your AI agent's job, then charges it rent for napping on the GPU.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/absurd-micro-startup-out node main.ts
```

This writes exactly that sentence to `entry.txt` in the output directory — one line, no trailing newline.
